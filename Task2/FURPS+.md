# FURPS+ Требования

| Код    | Требования                                                                                                      | Комментарий                                  |
| ------ | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| **F**  | **Функциональные (Functionality)**                                                                              |                                              |
| F1     | Пользователь видит список доступных депозитов со ставками, может подать заявку на новый депозит                 |                                              |
| F2     | Пользователь оставляет заявку на депозит, предавая номер телефона и ФИО                                         |                                              |
| F3     | Передаваемые с сайта данные шифруются                                                                           |                                              |
| F4     | В интернет-банке пользователь может просмотреть список своих депозитов, а также их состояние и историю операций | Улучшение UX                                 |
| F5     | В интернет-банке пользователь видит доступные депозиты с персонализированными ставками                          |                                              |
| F6     | В качестве второго фактора аутентификации использовать СМС-код                                                                 |                                              |
| F7     | В качестве системы уведомлений использовать СМС                                                                 |                                              |
| F8     | Сотрудник колл-центра может просматривать заявки на депозиты                                                    |                                              |
| F9     | Сотрудник фронт-офиса должен иметь возможность подтверждать (идентифицировать) клинтов в офисе                   |                                              |
| F10    | Сотрудник бэк-офиса кредитов подтверждает ставки в АБС                                                           | Из ландшафта                                 |
| F10    | Сотрудник бэк-офиса депозитов должен иметь возможность предоставить персонализированные ставки                   |                                              |
| **U**  | **Удобство использования (Usability)**                                                                          |                                              |
| U1     | Необходимо автоматизировать учет ставок по депозитам                                                            |                                              |
| U2     | Использовать систему дизайна, которая уже используется в банке                                                  |                                              |
| U3     | Интерфейс должен быть интуитивно понятным и простым в использовании                                             |                                              |
| **R**  | **Надёжность (Reliability)**                                                                                    |                                              |
| R1     | Все сервисы должны быть доступны работать 24/7 и быть доступны 99.9% времени                                    |                                              |
| R2     | Сервис должен быть устойчив к сбоям и обеспечивать восстановление после сбоев                                   |                                              |
| **P**  | **Производительность (Performance)**                                                                            |                                              |
| P1     | Отклик по всем операциям должен быть не более 300мс                                                             |                                              |
| P2     | Сервис должен уметь горизонтально масштабироваться                                                              |                                              |
| P3     | Сервис должен поддерживать репликацию между ЦОДами                                                              |                                              |
| **S**  | **Поддерживаемость (Supportability)**                                                                           |                                              |
| S1     | Необходимо документировать разрабатываемые решения                                                              |                                              |
| S2     | Как можно больше использовать существующие технологии или поддержать совместимость с ними                       |                                              |
| **+R** | **+ Ограничения (Restrictions)**                                                                                |                                              |
| +R1    | Функциональность отправки СМС нужно разработать внутри банка                                                    |                                              |
| +R3    | При необходимости, в качестве очереди сообщений использовать Kafka                                              |                                              |
| +R4    | Текущая версия платформы не поддерживает Kafka                                                                  |                                              |
| +R5    | Использовать микросервисную архитектуру                                                                         |                                              |
| +R6    | Нужно избежать прямой работы с АБС                                                                              |                                              |
| +R7    | АБС масштабируется только вертикально                                                                           |                                              |
| +R8    | Как можно больше использовать технологии, которыми уже владеют специалисты банка                                                                                 |                                              |
